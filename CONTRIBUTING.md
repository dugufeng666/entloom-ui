# Contributing to Entloom UI

## Before you start

- Read the README and check existing issues.
- Keep public platform code separate from private website and learning-center material.
- Do not commit credentials, customer data, screenshots containing private data or generated build output.

## Development checks

```bash
npm install
npm run typecheck
npm run build
```

For an interaction change, describe the user flow and include the API contract or mock data used by the screen.
